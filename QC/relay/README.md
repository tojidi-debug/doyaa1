# 전자공시 중계(구글 Apps Script) 설정 — 한 번만

1. https://script.google.com → [새 프로젝트] → 기본 코드를 지우고 `Code.gs` 내용을 붙여넣기 → 저장(프로젝트 이름: 품감 DART 중계).
2. 왼쪽 ⚙ [프로젝트 설정] → 맨 아래 [스크립트 속성] → [스크립트 속성 추가]
   - 속성: `DART_KEY` · 값: OpenDART 인증키(40자) → [스크립트 속성 저장]
   - **인증키는 코드·이 저장소에 적지 않습니다.** 스크립트 속성은 본인 구글 계정 안에만 있습니다.
3. 오른쪽 위 [배포] → [새 배포] → 톱니 → [웹 앱]
   - 실행 사용자: **나** · 액세스 권한이 있는 사용자: **모든 사용자** → [배포] → 권한 검토(본인 계정 → 고급 → 이동 → 허용)
4. 나온 **웹 앱 URL**(…/exec)을 `QC/qc/static/relay_config.js` 의 `window.QC_RELAY = '…'` 에 넣는다.
   - 시험: 웹 앱 URL 뒤에 `?op=ping` 을 붙여 열면 `{"ok":true,"op":"ping"}`.

주의: 웹 앱 URL 을 아는 사람은 이 세 기능(보고서 목록·원문·기업개황)을 본인 키 한도(OpenDART 하루 2만 건) 안에서 쓸 수 있습니다. 키 자체는 드러나지 않습니다.
코드를 고치면 [배포] → [배포 관리] → 연필 → 버전 「새 버전」 → [배포] (URL 은 그대로).
